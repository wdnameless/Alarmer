## ADDED Requirements

### Requirement: Logical Phased Tabs in Settings
The Settings view MUST be cleanly segregated into 3 logical isolated tabs (Sound & Audio, AI & Neural, Backup & Data) rather than an endless monolithic vertical list.

#### Scenario: User switches settings sub-themes
- **WHEN** user clicks "AI & Нейросети"
- **THEN** only AI API key and model parameters are displayed, hiding audio controls.
