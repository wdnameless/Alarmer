## ADDED Requirements

### Requirement: Upright Side Trigger for AI Sidebar
The AI trigger button on the edge of the window MUST be upright, un-inverted, and ergonomically readable.

#### Scenario: User views AI button
- **WHEN** user looks at the right edge
- **THEN** the button is neatly oriented with custom hand-drawn icon and upright label.

### Requirement: Split Side-by-Side Expanding Sidebar
The AI assistant MUST open as an expanding horizontal split sidebar on the right side of the window, allowing simultaneous visibility and interaction with the timer dial on the left.

#### Scenario: Opening AI sidebar
- **WHEN** user clicks the AI button
- **THEN** the window layout splits into Left: Timer Dashboard and Right: AI Assistant sidebar.

### Requirement: Bespoke Hand-Drawn Minimalist Icons
The application MUST use custom hand-drawn vector SVG icons rather than generic stock icon libraries.

#### Scenario: Icon rendering
- **WHEN** user views dashboard tabs and controls
- **THEN** hand-drawn stylized vector SVGs render instead of standard stock icons.
