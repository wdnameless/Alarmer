# Proposal: Competitive Reliability Program

## Why — критический дефект, найденный аудитом
`grep` подтвердил: логика срабатывания будильников живёт в `src/components/Alarms.tsx`,
который монтируется ТОЛЬКО при открытой вкладке «Алармы» (`DashboardView.tsx:81`).
Планировщик — `window.setInterval` внутри этого компонента (`Alarms.tsx:75`).

Результат: будильник НЕ звонит, когда открыта вкладка «Таймер» (режим по умолчанию),
«Настройки», когда окно скрыто в трей (крестик) или приложение закрыто.
Дополнительно WebView2 троттлит setInterval в скрытом окне.

Также `grep` подтвердил отсутствие: snooze, нарастания, повтора, автозапуска,
глобальных хоткеев; поле `alarm.sound` в типе есть, но `playFinishAlarm()` его игнорирует.

## Slices
- **W1** Rust-планировщик + автозапуск + нативное уведомление при скрытом окне
- **W2** Нарастание, повтор до подтверждения, Snooze, звук на каждый будильник
- **W3** Глобальные хоткеи + мини-оверлей
