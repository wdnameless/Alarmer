## ADDED Requirements

### Requirement: Attached Companion Window Mode
When the user toggles the AI assistant, the application MUST seamlessly present the AI in an attached side companion panel without squishing or resizing the primary 340px timer interface.

#### Scenario: User toggles AI button
- **WHEN** user clicks the AI side button
- **THEN** window smoothly expands to reveal the attached companion panel side-by-side.
