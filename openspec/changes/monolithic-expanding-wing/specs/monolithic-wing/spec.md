## ADDED Requirements

### Requirement: Unified Inseparable Companion Wing Layout
The application MUST house the timer and the AI companion inside a single physical desktop window that expands horizontally, guaranteeing zero window drift and a continuous visible connection.

#### Scenario: User toggles AI button
- **WHEN** user clicks the AI side button
- **THEN** the window expands to reveal the companion wing physically connected to the timer module.

#### Scenario: User drags the window
- **WHEN** user drags the window header
- **THEN** both modules move as one indivisible rigid unit.
