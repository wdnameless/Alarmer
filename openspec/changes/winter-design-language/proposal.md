# Proposal: Winter Design Language

## Why
Пользователь запросил стиль trywinter.app. DNA извлечён из живого CSS, не из описания.

**Что берём:** почти монохромная палитра с чистым чёрным #050505 · ступени высоты
поверхностей (+2..4 lightness) вместо теней · hairline-границы 1px · Inter для
подписей + JetBrains Mono для всех чисел · огромные пустоты · **один тёплый цвет
исключительно как маркер «сейчас»**.

**Что НЕ берём:** колоночную структуру календаря (у будильника другая задача),
отказ от круга (циферблат — наша отличительная фича).

**Ключевой приём:** в Winter оранжевый не является акцентом темы — им помечено
текущее время. Мы используем то же правило: оранжевый = «сейчас», ничего больше.

**Собственное решение поверх референса:** Winter однороден и спокоен, но будильник
обязан разбудить. Вводим контраст состояний — покой до звонка, тёплая заливка
экрана при срабатывании.

## Waves
- **W1** Токены Winter + шрифты + циферблат + список алармов (главный экран)
- **W2** Экран звонка: тёплый контраст + нарастание
- **W3** AI-крыло, настройки, оверлей
