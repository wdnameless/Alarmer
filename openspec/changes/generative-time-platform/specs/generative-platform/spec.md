## ADDED Requirements

### Requirement: Fluid Responsive Scaling
The application SHALL adapt its layout continuously to arbitrary viewport dimensions using flex/grid and dynamic SVG radius without breaking layout bounds.

#### Scenario: Continuous Window Resize
- **WHEN** user resizes window to any width (from 200px to 1920px)
- **THEN** dial and controls maintain proportional aspect ratio without overflowing or clipping.

### Requirement: AI Co-Pilot Chat Sidebar
The application SHALL provide an omnipresent AI Assistant drawer enabling natural conversation to reshape the interface and schedule routines.

#### Scenario: Chat-Driven Interface Morph
- **WHEN** user sends request "Сделай дашборд для интенсивной тренировки с ярким красным акцентом и крупными кнопками"
- **THEN** AI generates layout and theme mutations and applies them instantly with audio confirmation.

### Requirement: Full Scenario Orchestration
The AI Assistant SHALL have authority to create, modify, and activate workouts, interval timers, and alarm clocks simultaneously with visual updates.

#### Scenario: Combined Routine and Style Prompt
- **WHEN** user requests a study pomodoro session with relaxing green theme
- **THEN** UI adopts emerald palette, timer configures 50/10 intervals, and break alarms are registered.
