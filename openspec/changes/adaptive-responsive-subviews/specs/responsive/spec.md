## ADDED Requirements

### Requirement: Responsive Auto-Fitting for Sub-Views
All sub-views (Alarms, Workout Player, Settings) MUST adapt their layout to container width without horizontal clipping or scrollbars.

#### Scenario: User navigates to Alarms view
- **WHEN** user opens Alarms tab
- **THEN** all header buttons, input fields, and action buttons fit comfortably inside the visible container with zero right-side clipping.
